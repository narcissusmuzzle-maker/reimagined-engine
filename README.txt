U613 Stat — версия 1.0.2. Новое приложение для Amazfit Bip Max: статистика LuvU613 восемью цветными полосками (как виджет статистики на телефоне).
Приложение «Таймер» не менялось и ставится отдельно. U613 Stat работает в паре с LuvU613 5.13 (архив LuvU613-app-5_13.zip): в 5.12 и старше ответа на запрос статистики нет.

ЧТО НА ЭКРАНЕ
- Чёрный экран, восемь полосок по 380 px, у каждой три сегмента: месяц | неделя | день (слева направо). Текста нет.
- Полоска 1 — слова (в виджете там четыре сегмента, «всего» на часах нет). Полоска 2 — все занятия вместе. Ниже с эмодзи сверху: 🩸 🎨 🤿 💀 🧬 📖.
- Цвета и цели те же, что в виджете: их считает телефон (LuvU613 5.13), часы только рисуют.
- Размеры по вашему описанию: поля 26 px, сегменты 125 / 125 / 124 с зазорами 3 px, две верхние полоски 36 px через 18 px, шесть нижних по 26 px,
  эмодзи 24 px по центру за 2 px до своей полоски, шаг между подписанными полосками 58 px.

КАК УСТАНОВИТЬ (так же, как «Таймер»)
1. Создайте НОВЫЙ репозиторий на GitHub и загрузите в него ВСЁ из этой папки (Add file -> Upload files). Скрытых папок в архиве нет.
   Файл сборки: Add file -> Create new file, имя .github/workflows/build.yml, внутрь текст из файла build.yml.
2. Вкладка Actions: дождаться зелёной галочки у первой сборки (Build watch app). Это ещё не готово к установке.
3. Settings -> Pages: в «Build and deployment» выбрать Source = Deploy from a branch, ветка gh-pages (её создала первая сборка), папка / (root), Save.
   Во вкладке Actions запустится вторая сборка «pages build and deployment» — дождаться зелёной галочки. QR-код появляется только после неё:
   на странице Settings -> Pages сверху будет ссылка на сайт (https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/) — открыть её, на ней QR-код.
4. В Zepp: Профиль -> часы -> Режим разработчика -> сканировать этот QR-код.
5. Приложение на телефоне обновите до LuvU613 5.13. Zepp и LuvU613: батарея «Без ограничений».
Приложение называется «U613 Stat», у него свой номер (appId 1061613), с «Таймером» не пересекается.

КАК РАБОТАЕТ
- При открытии приложения часы спрашивают телефон и красят полоски; пока приложение открыто, повторяют раз в минуту.
  Последние цвета хранятся на часах: при открытии сразу видна прошлая картина, новая появляется, когда телефон ответит (обычно за секунду).
- Нет связи: остаются прошлые цвета. Если их ещё не было — серые (так же в виджете, когда данных нет).
- При включении экрана приложение открывается заново и сразу обновляется (как «Таймер»). Не нужно — в page/index.js поставьте WAKE_RELAUNCH = false.
- Нажатие на пустое (чёрное) место — обновить сейчас. Долгое нажатие на пустое место — на 8 секунд показать, когда телефон отвечал в последний
  раз, сколько запросов и почему не вышло (например «обновите LuvU613 до 5.13»).
- Выход — свайпом вправо, как у обычных приложений.

ПОЛОЖЕНИЕ ПО ВЕРТИКАЛИ
Сделано так же, как в «Таймере»: страница поднята на 31 px (в page/index.js «const DOWN = 33», LIFT = 64 - 33). Каждый y из вашего описания
(первая полоска на 48, последняя кончается на 494) ставится на странице на 31 px выше: первая полоска на 17, низ последней на 463.
Если на часах не так: page/index.js, строка «const DOWN = 33» с комментарием. Сверху обрезано — число БОЛЬШЕ, снизу обрезано — МЕНЬШЕ (от 16 до 64);
двигаются сразу все полоски и эмодзи. Положение на живых часах я проверить не могу — только это число может понадобиться подправить.
